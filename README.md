# BCM Developer Test

This folder contains the code and assets for the developer-test questions.

## View the HTML questions in a browser

For a quick preview, open the folder in Finder and drag an `index.html` file into
an open browser window. You can also double-click an HTML file to open it in your
default browser.

- Question 04: open `question-04/index.html`.
- Questions 05 and 06: open `question-05-&-06/index.html`.

Keep each question's related files in their folders. The HTML pages load their
CSS, JavaScript, and images using relative paths, so moving an HTML file by
itself can prevent those assets from loading.

## View the PHP question

Question 01 is in `question-01/content-solution.php`. A PHP file cannot be
previewed as a working page by dragging it into a browser: the browser will
show its source rather than execute it. PHP must run through a PHP-enabled web
server, and this solution also uses WordPress functions. To see it rendered,
run the WordPress site in the Local application and load the template through
WordPress; opening the PHP file directly will not render it.

## Inspect the code

You can open any `.html`, `.php`, `.css`, or `.js` file in a code editor to read
or edit its source. Dragging a code file into a browser is not a substitute for
running PHP or JavaScript in its intended environment.
